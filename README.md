# 💎 Diamond Price Prediction

A regression project that predicts diamond prices from physical characteristics (carat, dimensions) and quality grades (cut, color, clarity). It benchmarks nine regression algorithms and identifies the factors that influence diamond valuation, to support data-backed pricing decisions in the industry.

## Highlights

- Regression on 53,940 diamonds (53,917 after cleaning)
- Data cleaning for invalid and extreme dimension values
- Engineered `volume` feature plus ordinal encoding of cut, color, and clarity grades
- Benchmark of 9 regression models; **XGBoost performed best with R² ≈ 0.98**
- Adding the quality grades lifted the best model's R² from 0.89 to 0.98
- Residual analysis and a saved model for reuse

## Dataset

The dataset (`diamonds.csv`) contains 53,940 diamonds with no missing values.

| Column | Description |
|--------|-------------|
| `carat` | Weight of the diamond |
| `cut` | Cut quality (Fair, Good, Very Good, Premium, Ideal) |
| `color` | Color grade, from J (worst) to D (best) |
| `clarity` | Clarity grade, from I1 (worst) to IF (best) |
| `depth` | Total depth percentage |
| `table` | Width of the top of the diamond relative to its widest point |
| `x`, `y`, `z` | Length, width, and depth in mm |
| `price` | **Target:** price in US dollars |

## Approach

1. **Exploratory data analysis**
   - Checked shape, data types, missing values, and summary statistics.
   - Analyzed correlations with price and inspected outliers with boxplots.
   - Compared the original price distribution with its log transformation.
2. **Data cleaning**
   - Dropped the redundant index column.
   - Removed rows with zero-valued dimensions and extreme outliers (`y` of 20 or more, `z` of 10 or more).
3. **Feature engineering**
   - Created `volume` as x multiplied by y multiplied by z.
   - Mapped `cut`, `color`, and `clarity` to ordinal scores that preserve their quality order (for example, J = 1 to D = 7 for color).
4. **Modeling**
   - 80/20 train/test split.
   - Compared Linear Regression, Ridge, Lasso, ElasticNet, Decision Tree, Extra Tree, K-Neighbors, Gradient Boosting, and XGBoost.
5. **Evaluation**
   - Scored models with R², RMSE, and MAE, and examined the Linear Regression residuals with a KDE plot and a residuals plot (`yellowbrick`).
6. **Export**
   - Saved the processed dataset (`kc_diamond.pkl`) and the trained model (`diamond_regression.pkl`).

## Results

Test set results (errors are in US dollars):

| Model | R² | RMSE | MAE |
|-------|-----|------|-----|
| **XGBoost** | **0.9821** | **531** | **273** |
| Gradient Boosting | 0.9774 | 596 | 336 |
| Decision Tree | 0.9680 | 710 | 344 |
| Extra Tree | 0.9668 | 724 | 347 |
| K-Neighbors | 0.9628 | 765 | 388 |
| Linear Regression | 0.9143 | 1,162 | 773 |
| Ridge | 0.9143 | 1,162 | 773 |
| Lasso | 0.9142 | 1,163 | 774 |
| ElasticNet | 0.9087 | 1,199 | 803 |

Tree-based and ensemble models clearly outperform linear models, which suggests non-linear relationships between size, quality grades, and price. XGBoost predicts diamond prices with an average error of about $273 (MAE).

Including the encoded quality grades made a large difference. Before they were added, the best model (Gradient Boosting) reached R² ≈ 0.89 using physical measurements only; with `cut`, `color`, and `clarity`, the best model reaches R² ≈ 0.98. Carat weight is still the strongest single predictor (correlation of 0.92 with price), followed by the dimensions x, y, and z (0.86 to 0.88), while depth and table percentages show little linear relationship with price.
